# chaoxing_bbsDuplicateComment

学习通课程讨论的单话题 Tampermonkey 脚本。它只在话题详情页显示控制面板，不接管讨论列表，也不会自动打开其他页面。

## 安装

1. 在 Edge 或 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/)，确认扩展已启用。
2. 如果使用 Tampermonkey 5.3 或更新版本，打开浏览器的扩展管理页（Edge 为 `edge://extensions`），进入 Tampermonkey 的“详细信息”，启用“允许用户脚本”。如果没有这个开关，可在扩展管理页启用“开发人员模式”。具体位置见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q209)。
3. 打开仓库中的 [`chaoxing-topic-replies.user.js`](./chaoxing-topic-replies.user.js)，点击 GitHub 页面右上方的 **Raw**。浏览器应显示 Tampermonkey 的安装确认页；核对脚本名称和匹配地址后点击“安装”。如果没有弹出安装页，可按下方“手动安装”操作。此方式参照 [Tampermonkey 官方安装说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q102)。
4. 在 Tampermonkey 管理面板确认“学习通讨论话题回复队列”已启用。登录学习通，打开一张课程讨论的**话题详情页**并刷新，右上角应出现“当前话题回复”面板。讨论列表页不显示面板是正常情况。

### 手动安装或更新

1. 在 GitHub 打开脚本文件，点击 **Raw**，复制全部代码，包括开头的 `// ==UserScript==` 元数据。
2. 新安装：点击 Tampermonkey 图标 →“管理面板”→“添加新脚本”，删除编辑器内的默认模板，粘贴代码并保存。
3. 更新已有脚本：在管理面板打开同名脚本的编辑器，用新代码替换旧代码并保存；不要同时保留两个启用的副本。此脚本没有配置自动更新地址，仓库更新后需要手动更新。
4. 回到话题详情页刷新，确认面板出现。已保存的本题文字与计数位于浏览器本地存储，正常更新脚本不会清除；刷新前请自行保存网页原生回复框中尚未提交的草稿。

## 使用

1. 正常登录学习通，自行打开要回复的话题。发布时尽量只保留这一张课程讨论页面；其他话题详情页或讨论列表页可能触发网站的“请勿同时在多个网页发布”提示。脚本也会拒绝在检测到另一张话题详情页时启动。
2. 在面板填写与当前话题相关的回复文字、计划回复数、间隔和冷却时间。输入及进度自动保存在当前浏览器中。
3. 点击“开始或继续”。脚本使用网页原有的回复按钮提交，只处理当前话题；点击“暂停”可停止后续回复。若当前请求已经发出，它仍可能完成。
4. 默认每条间隔 2 秒；网站明确提示“操作过于频繁”时，先等待 1 分钟再试。连续限流会逐次延长等待，单次最多 60 分钟。冷却中可以暂停；刷新页面后需手动点击“开始或继续”。脚本不会绕过网站的审核、截止时间或发布限制。
5. 只有页面明确返回成功或待审核，计数才会增加。若请求结果不明，脚本会停止；请先在网页核实，再点击“核实后继续”按弹窗提示输入结果，无法确定时取消，避免重复提交。

如果上次失败后网页回复框仍留着与本题设置相同的文字，继续时会直接用它提交；若文字不同，脚本会停止并提示核对。脚本会对同一道题重复提交所填文字，请遵守课程和平台规则。

## 面板不显示时

- 确认当前 URL 是 `groupweb.chaoxing.com` 的**话题详情页**，路径包含 `/course/topic/v3/bbs/` 且以 `/replysList` 结尾；讨论列表页不匹配。
- 在 Tampermonkey 管理面板确认脚本只有一个启用的副本，并检查 Edge/Chrome 的“允许用户脚本”或开发人员模式是否已开启。
- 保存脚本后重新加载详情页。若仍不显示，检查浏览器是否阻止扩展在该网站运行。

脚本不保存账号密码或 Cookie；回复文字和进度仅保存在 `groupweb.chaoxing.com` 的浏览器本地存储。旧版多话题队列数据不会用于此版本。
